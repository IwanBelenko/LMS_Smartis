# Smartis LMS

Корпоративная LMS для обучения сотрудников Smartis.

## Что уже работает

- вход по email и паролю;
- роли администратора, автора, руководителя и сотрудника;
- отделы и приглашения сотрудников;
- административный список пользователей;
- конструктор курсов с текстовыми, видео-, ссылочными и файловыми уроками;
- визуальный редактор текста: заголовки, шрифты, размеры, цвета, списки, цитаты, ссылки и выравнивание;
- загрузка видео на платформу с хранением в отдельном Docker-томе;
- стандартные и пользовательские обложки курсов;
- импорт ZIP-пакетов SCORM 1.2 и экспорт курсов Smartis в SCORM 1.2;
- редактирование карточки импортированного SCORM-курса и замена пакета новой версией;
- преобразование лонгридов iSpring в редактируемую копию Smartis с главами, текстом и вопросами;
- предварительный просмотр обычных и SCORM-курсов прямо в LMS;
- черновики, версии, публикация и снятие курсов с публикации;
- отдельные права администратора, автора и сотрудника для работы с курсами;
- учебный дашборд и рейтинг;
- светлая и тёмная темы;
- запуск через Docker Compose.

## Запуск через Docker

~~~bash
cp .env.example .env
docker compose up --build
~~~

Откройте http://localhost. Для первого локального входа:

- email: admin@smartis.local
- пароль: SmartisDemo123!

Перед публикацией на сервере обязательно замените пароль и секреты в .env. Для
SCORM-плеера укажите отдельный поддомен в `SCORM_HOST` и полный адрес этого
поддомена в `SCORM_CONTENT_ORIGIN`: это изолирует импортированные курсы от
авторизации и интерфейса LMS.

## Состав проекта

- frontend — React + TypeScript;
- backend — Django REST API;
- infra — Caddy;
- compose.yaml — PostgreSQL, Redis, MinIO, API и веб-интерфейс.
